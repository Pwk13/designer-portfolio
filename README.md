# 平面视觉设计师作品集网站（彭文凯）

基于 **React + Vite** 的 PC 端作品集单页网站：暗色高级科技风（参考风格：亮绿点缀），版心 1680px，整页翻动式滚动，五屏结构完整可编辑。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 本地开发，浏览器打开 http://localhost:5173
npm run build   # 生产构建，产物输出到 dist/
npm run preview # 预览构建产物
```

## ✏️ 站内编辑模式（无需改代码即可改文字和图片）

页面右上角点击 **「✎ 编辑」** 进入编辑模式：

- **改文字**：直接点击页面上的任意文字（姓名、标题、介绍、作品说明、联系方式等），光标出现后即可修改；按 `Enter` 保存、按 `Esc` 取消。
- **换图片**：编辑模式下点击任意作品图片 / 背景角色图，会弹出文件选择框，选好新图即替换（保存到浏览器本地）。
- **添加作品**：工具栏「＋ 添加作品」→ 输入标题与分类（可填新分类，自动加入分类栏）→ 选择本地图片即添加为新卡片（默认横屏滚动区末尾）。
- **删除作品**：编辑模式下每张作品卡右上角出现 ✕ 按钮，点击确认后即删除该作品。
- **添加分类**：工具栏「＋ 添加分类」，或在作品区筛选栏点击「＋ 分类」，输入名称即可新增一个作品分类（并可筛选）。
- **导出 / 导入 / 恢复默认**：编辑模式右下角浮动工具栏提供「导出修改」（下载 `portfolio-edit.json`，可备份或换电脑导入）、「导入修改」、「恢复默认」。
- 所有修改保存在浏览器 `localStorage`（key：`portfolio-edit-v1`），刷新页面后依然保留。
- 再次点击「✓ 完成编辑」退出编辑模式。

> 提示：如果不小心改乱了，点「恢复默认」即可一键还原初始内容。

        ├── About.jsx          # 个人经历（潮流角色背景行走 + 介绍 + 项目数据）
        ├── Works.jsx          # 作品展示（横屏滚动 + 点击放大 + 设计说明）

        ├── Contact.jsx        # 页尾联系方式
        ├── EditToolbar.jsx    # 编辑模式浮动工具栏
        ├── DotNav.jsx         # 右侧翻页导航点

## 修改网站内容

所有文字与数据集中在 `src/data/profile.js`：

- **姓名 / 职业 / 简介**：`name`、`role`、`intro` 等字段
- **项目数据**：`stats` 数组（实习段数、学习年数、课程数、方向数）
- **能力值**：`skills` 数组（雷达图与进度条自动更新）
- **联系方式**：`email`、`phone`、`school`、`location`、`socials`
- **作品（当前 28 幅，全部真实作品）**：替换 `public/assets/works/` 下的图片（保持文件名或同步修改 `works` 数组的 `image` 路径），并修改 `title / category / year / desc / span(列宽 1-12，本站大卡 7 / 小卡 5) / aspect(宽高比)`
- **作品分类**：`categories` 数组（默认 全部/品牌/海报/插画/UI，可在编辑模式添加）
- **背景潮流角色**：`walker` 字段（`img1/img2` 行走双帧、`wave` 挥手帧、`hello` 悬停问候语）——透明 PNG，悬停人物时停步挥手并显示"你好！"
- **配色**：修改 `src/index.css` 顶部 `:root` 中的 `--cyan`（亮绿主色）与 `--violet`（薄荷辅色）即可整体换色

> 社交平台（站酷/Behance/小红书/即刻）当前为平台入口占位链接，可替换为你自己的主页地址。
